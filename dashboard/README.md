# Dashboard

This folder contains the final **Sales Analysis Dashboard** developed as part of the Excel Sales Analytics project.

## Dashboard Preview

The dashboard provides an interactive overview of sales performance and business activity using data from the Products, Customers, and Orders datasets.

### Dashboard Image

![sales_analysis_dashboard](dashboard.png)

## Key Performance Indicators

The dashboard highlights the following key metrics:

- **Total Orders:** 1,000
- **Total Revenue:** ₹35,20,984
- **Average Order-Delivery Time:** 5.53
- **Average Customer Spend:** ₹3,520.98

## Analysis Included

The dashboard provides visual analysis of:

- Revenue by Category
- Top 10 Cities by Orders
- Revenue by Month
- Revenue by Occasion
- Revenue by Order Hour
- Top 5 Products by Revenue

## Interactive Filters

The dashboard includes interactive filters that allow users to analyze the data based on:

- **Order Date**
- **Delivery Date**
- **Occasion**

These filters allow users to explore the dashboard from different business perspectives and focus on specific periods or occasions.

## Dashboard Development

The dashboard was created using:

- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Slicers / Filters

The source datasets were first imported and transformed using Power Query. The cleaned data was then used to create Pivot Tables and visualizations that form the basis of the final dashboard.

## Purpose

The purpose of the dashboard is to transform raw sales data into an interactive and easy-to-understand business reporting tool that can help identify:

- Revenue trends
- High-performing product categories
- Top-performing cities by order volume
- Important sales occasions
- Peak sales periods
- Top revenue-generating products
- Delivery performance

> **Note:** The dashboard image is provided as a visual preview. For the complete interactive experience, open the Excel workbook available in the `excel/` folder.
