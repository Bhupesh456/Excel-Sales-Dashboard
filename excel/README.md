# Excel Project

This folder contains the main Excel workbook used to develop the **Sales Analysis Dashboard**.

The workbook contains the complete analysis workflow, from data preparation and transformation to Pivot Table analysis and dashboard creation.

## Main File

### `Sales_Dashboard.xlsx`

This is the primary project file.

The workbook was created using **Microsoft Excel** and includes:

- Data imported using **Get Data**
- Data cleaning and transformation using **Power Query**
- Pivot Tables for analysis
- Pivot Charts for visualization
- Interactive dashboard
- Key Performance Indicators (KPIs)
- Filters and slicers for interactive analysis

## Data Preparation

The project began with three datasets:

- Products
- Customers
- Orders

These datasets were imported into Excel and processed using **Power Query**. Data corrections and transformations were performed before the prepared data was used for analysis.

## Dashboard Analysis

The dashboard provides an interactive overview of sales performance, including:

- Total Orders
- Total Revenue
- Average Customer Spend
- Average Order-Delivery Time
- Revenue by Category
- Top Cities by Orders
- Revenue by Month
- Revenue by Occasion
- Revenue by Order Hour
- Top 5 Products by Revenue

Users can interact with the dashboard using filters for:

- Order Date
- Delivery Date
- Occasion

## How to Use

1. Download `Sales_Dashboard.xlsx`.
2. Open the workbook using Microsoft Excel.
3. Navigate through the relevant worksheets to review the data preparation, analysis, Pivot Tables, and dashboard.
4. Use the available filters and slicers to interact with the dashboard.

> **Note:** Some Power Query functionality and interactive features may require Microsoft Excel rather than alternative spreadsheet applications.

## Project Output

The completed workbook provides an interactive sales dashboard designed to transform raw transactional data into meaningful business insights and support data-driven decision-making.
